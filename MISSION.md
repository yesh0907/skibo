# Mission: Build Skip-Bo With Agentic Engineering

## Why
Ship a correct multiplayer Skip-Bo game quickly with Codex while retaining enough technical understanding to evaluate, debug, and extend what the agent builds.

## Success looks like
- Explain the important state, rule, and infrastructure boundaries in the finished system
- Trace a player command from client input through validation, persistence, and broadcast
- Recognize the correctness properties and tradeoffs behind each implementation slice
- Use focused teaching artifacts to review the system without slowing routine delivery

## Constraints
- Optimize implementation sessions for speed and correctness
- Produce a concise technical lesson after every completed slice
- Focus lessons on code behavior and design rather than routine repository management

## Out of scope
- Manually implementing every high-learning component
- Turning every routine code edit into an interactive teaching pause
