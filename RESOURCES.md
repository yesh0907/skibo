# Skip-Bo Agentic Engineering Resources

## Knowledge

- [Mattel: Official Skip-Bo Instructions](https://service.mattel.com/instruction_sheets/42050-0520.pdf)
  Primary source for legal sources, build-pile order, discard behavior, drawing, and winning.
- [TypeScript Handbook: Narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)
  Primary language reference for the discriminated unions used by game commands and card sources.
- [TypeScript 3.7: Assertion Functions](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-7.html#assertion-functions)
  Primary language reference for functions that return normally only when a runtime condition holds.
- [Bun: Writing Tests](https://bun.sh/docs/test/writing-tests)
  Primary runtime reference for the test structure and assertions used by the engine suite.
- [Martin Fowler: Test Invariant](https://martinfowler.com/bliki/TestInvariant.html)
  Short reference on expressing conditions that must remain true across many operations.
